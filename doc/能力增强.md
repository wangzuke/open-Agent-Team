# open-teams 7 项能力增强整理版
## 一、背景
open-teams 目前仅具备 13 个文本工具与同步 LLM 调用能力，缺失 AI coding agent 核心能力。我希望补齐**安全沙箱、API 重试、上下文压缩、Token 预算、流式输出、Git 集成、多模态**7 项能力。

## 二、能力定位：工具 vs 基础设施
| 能力 | 定位 | 核心原因 |
|------|------|----------|
| 安全沙箱 | 基础设施 | 透明封装现有工具，Agent 无感知 |
| API 重试 | 基础设施 | 属于 LLM 客户端内部逻辑 |
| 上下文压缩 | 基础设施 | 自动触发，Agent 无感知 |
| Token 预算 | 基础设施 | 自动追踪限制，无需 Agent 调用 |
| 流式输出 | 基础设施 | 依托 LLM 客户端+终端回调实现 |
| Git 集成 | 工具（4 个） | Agent 需主动执行 Git 操作 |
| 多模态 | 增强 read_file | 扩展现有工具，不新增独立工具 |

## 三、文件改动总览
### 新增文件（3 个）
- `utils/security.py`：沙箱校验函数
- `runtime/token_tracker.py`：Token 累计追踪器
- `tools/git_tools.py`：4 个 Git 工具

### 修改文件（11 个）
`config.py`、`runtime/llm_client.py`、`runtime/context.py`、`runtime/engine.py`、`tools/file_tools.py`、`tools/shell_tool.py`、`tools/registry.py`、`logging/activity_logger.py`、`agents/manager.py`、`agents/leader.py`、`main.py`


## 五、7 项能力实现要点
### 1. 安全沙箱
- 新建 `security.py`：定义沙箱异常，校验危险 shell 命令与敏感文件路径
- 改造 `shell_tool.py`：执行前校验命令，捕获违规并返回错误
- 改造 `file_tools.py`：校验文件读写路径，限制在项目目录/允许目录内
- 改造 `registry.py`：传递配置并注册 Git 工具

### 2. API 重试
- `llm_client.py` 新增指数退避重试函数，识别 429/5xx 等可重试异常
- 为 Anthropic/OpenAI 客户端添加重试逻辑，工厂函数支持重试次数配置

### 3. 上下文压缩
- `context.py` 新增 Token 估算与压缩逻辑：超 80% 阈值时保留首条+最后 6 条消息，中间内容启发式摘要
- 压缩切割保证 tool_use/tool_result 成对，避免 API 报错
- `engine.py` 每轮循环前自动触发压缩

### 4. Token 预算与成本追踪
- 新建 `token_tracker.py`：统计输入/输出 Token，估算美元成本
- `activity_logger.py` 新增 Token 使用日志
- `engine.py` 实时累加用量，超预算时发送系统警告并终止运行

### 5. 流式输出
- `llm_client.py` 抽象流式接口，分别实现 Anthropic/OpenAI 流式调用与回调
- 流式+重试兼容：失败重启流，允许少量重复输出
- `engine.py` 支持传入回调，根据配置切换流式/非流式

### 6. Git 工具
- 新建 `git_tools.py`：实现 `git_status`/`git_diff`/`git_log`/`git_commit` 4 个工具，截断大 diff、安全提交
- `registry.py` 完成工具注册

### 7. 多模态
- `file_tools.py` 识别图片/PDF，图片转 base64 标记，PDF 提取文本
- `engine.py` 检测图片标记并转为模型支持的内容格式
- `llm_client.py` 兼容多模态消息结构

## 六、配置与 CLI 新增项
### Config 新增字段
```python
sandbox_enabled: bool = True
sandbox_allowed_dirs: list = field(default_factory=list)
max_retries: int = 3
max_context_tokens: int = 100_000
token_budget: int = 0
streaming: bool = True
```
Worker 代理强制关闭 `streaming`。

### CLI 新参数
- `--no-sandbox`：禁用安全沙箱
- `--no-stream`：禁用流式输出
- `--token-budget N`：设置 Token 预算
- `--max-retries N`：设置 API 最大重试次数

## 七、功能验证项
1. 安全沙箱：拦截高危命令/敏感路径写入，关闭沙箱则放行
2. API 重试：模拟 429 可正常重试成功
3. 上下文压缩：长对话自动压缩并出现摘要标记
4. Token 追踪：日志记录用量，超预算提前终止
5. 流式输出：终端逐字实时输出
6. Git 工具：4 个 Git 操作正常执行
7. 多模态：读取图片可被 LLM 正常识别描述
